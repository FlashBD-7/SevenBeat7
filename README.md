## 主页音乐

首页随身听和设置页提供 Sympathy、Merry Go、The Builder、Happy Boy End Theme 四个选项，所选歌曲循环播放。来自用户本次提供的视频，提取音轨后统一了适合主页播放的响度；默认音量 35%，与游戏音乐及语音音量独立。

开始游戏时立即停止主页音乐。暂停、结算、谱面工坊试听、校准和录制期间不播放，返回待机主页后继续；设置界面可选择并试听主页音乐。它不会混入游戏录制音轨。

浏览器首次访问可能禁止有声自动播放，此时页面显示提示，点击页面即可在开关已开启时解锁播放；「关闭主页 BGM」会关闭音乐，「开启主页 BGM」会重新开启。关闭开关、选曲和音量均保存到本机。

## 操作与判定

| 操作 | 作用 |
| --- | --- |
| D | 空中轨道，短按击打，长条按住 |
| J | 地面轨道，短按击打，长条按住 |
| 先按住 D，再按 J | 保持空中，触发下劈；仍能避开齿轮 |
| 先按住 J，再按 D | 保持地面，触发上撩；不会因此避开齿轮 |
| 松开后按的键 | 解除交叉姿势，保持第一键高度 |
| ESC / Space | 暂停、继续 |
| R | 从当前游玩起点重来 |

先按住的键决定高度，谱面和判定不会在手动模式下自动抬高或压低人物。跳齿轮前需松开地面键，再按空中键。屏幕按钮和自定义键位采用相同规则。

短按、长按头尾使用新的 70 / 150 ms 判定窗口。延迟补偿范围 −500～+500 ms；例如总是慢 50 ms，可先尝试 +50。齿轮仍检查接触时是否在空中，不采用击打时间窗口。

## 配色与图案

设置页「乐句配色 × 怪兽图案」提供青蓝、粉、薄荷、紫、黄、橙六组映射；每组可选择飞翼独眼、尖角怪兽、蝙蝠、兔子、星星、猫耳音箱、飞碟或果冻。不同 ID 不会再触发随机外观。谱面中的明确颜色优先，未指定颜色的音符使用空中 / 地面默认色。

三首整理谱面与原创曲按乐句写入明确颜色，在同一乐句内保持稳定。工坊选中音符后，可修改「音符颜色」和「外观」；明确指定的外观优先于颜色映射。颜色和明确图案可随 JSON 导出、导入；个人颜色映射偏好保存在本机设置中。

自定义贴图优先于内置图案，并保留导入图片的原色。背景、人物、怪兽、长按头部与齿轮仍可分别替换，支持等比尺寸预览和显示比例设置。推荐背景 1920 × 1080、怪兽 / 齿轮 256 × 256、人物 768 × 768；保存时每张不超过 400 万像素、单边 4096 px、12 MB。显示比例不改变判定。

## 创作与录制

工坊支持歌曲导入、按时间轴放置 / 拖动短按和长按、齿轮、节拍吸附、逐音符属性编辑、实时录入、撤销、保存和 JSON 导出。勾选「包含音乐」可导出一个可直接携带游玩的 JSON。未包含音乐时，另行导入对应音频。

录制支持实际 MP4、720p、目标 30 / 60 帧、选择是否保留游戏 UI。录入游戏 BGM、成功音效、角色语音；自然结束时保留庆祝与完整语音尾段。纯画面录制隐藏 HUD 和文字，保留场景、角色与特效。手动停止或离开舞台会结束当前录制。

零 MISS 完成整首非空谱面显示 FULL COMBO，GOOD 也计为命中；AUTO 结果明确标注，从游标练习不显示整曲全连。Combo 大于 10 持续闪耀。结束语音按命中率选择：大于 80% 赞扬，60%–80% 鼓励，小于 60% 嘲讽；每次有效结算有独立 0.1% 彩蛋概率。开始 / 重来随机播放开始语音。

字体沿用华康少女文字专用封装，分发包没有独立 TTF / OTF；本地运行无法保证绝对防提取，详见 [字体说明](FONT-PACKAGING.md)。六种循环背景、环境粒子、弹性动画、四张 UI 装饰和九段语音均保留。

## 简单模式与手机操作

简单谱面只从标准谱面选取原有事件，保留对应时间、长按尾点和乐句颜色；空中与地面之间也限制最短间隔，不安排双押或交叉长按。在独立齿轮前后留出跳跃空间。Unwelcome School 简单版只含短按与闪避，其余两首保留少量长按。

手机建议横屏，点击舞台右上角「⛶」放大。直接点对应光圈或下面的空中 / 地面按钮；按住后移出按钮仍保持，松手或触摸取消时解除。长按期间可用另一指击打另一行。全屏右上角「Ⅱ」暂停；切到其他应用时自动暂停。节拍校准支持点「跟拍」按钮，不需要外接键盘。

轻量版是独立文件夹，音乐通过离线素材包共享，不会为简单谱面重复存一首歌。角色和装饰图片缩小并无损编码为 WebP，字体继续封装，原游戏音频保持不变。可直接部署到静态网站，手机通过网页地址打开；手机文件管理器的 HTML 预览可能禁用脚本。

开发者构建轻量版：先运行 `node tools/rebuild-bundle.cjs`，再运行 `python tools/build-lite.py`（需要 Pillow）。默认输出到并列的 SevenBeat-Lite 文件夹，构建时检查体积上限。构建脚本实际移除功能代码与对应素材，不只是隐藏按钮。
